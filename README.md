# Consulta de CT-e

Base mínima para normalizar resultados de CT-e já obtidos por fonte autorizada e relacioná-los às NF-e vinculadas. É útil para iniciar uma tela de pesquisa, API interna ou importador de XML.

O projeto não oferece acesso público à SEFAZ, não contém certificado e não simula autorização fiscal.

```bash
npm install
npm run check
```

Use [AGENTS.md](./AGENTS.md) como contexto ao continuar o desenvolvimento com sua IA.

## 🇬🇧 English

**CT-e lookup.** Minimal base to normalize CT-e (electronic freight document) results obtained from an authorized source and link them to related NF-e. Useful to start a search screen, internal API or XML importer. It does not access SEFAZ, contains no certificate and does not simulate fiscal authorization.

```bash
npm install
npm run check
```
